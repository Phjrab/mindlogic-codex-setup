Windows 호환 수정 및 검증 — 2026-09-30 (Asia/Seoul)

원본: https://github.com/Phjrab/mindlogic-codex-setup
검증 환경: Windows, Python 3.12.10, Codex CLI 0.159.0

수정 내용
1. macOS LaunchAgent 외에 Windows 사용자 작업 스케줄러를 지원합니다.
   라우터는 로그온 시 실행하고, 선택적인 채팅 동기화는 60초 간격으로 실행합니다.
   사용자 로그인 세션과 Limited 실행 수준을 사용하며 비밀번호를 저장하지 않습니다.
2. Windows 설치의 기본 동작은 기존 OpenAI 설정을 유지하는 별도 프로필입니다.
   menu-install: mindlogic-menu.config.toml
   install: mindlogic.config.toml
   기본 앱 제공자 변경은 명시적인 menu-activate / --activate로 분리했습니다.
3. UTF-8 및 UTF-8 BOM 파일을 처리하고 Windows .cmd 실행 명령을 만듭니다.
4. app-server 파이프를 select 대신 reader thread와 queue로 읽습니다.
5. Windows 파일 잠금은 msvcrt를 사용하며 SQLite 연결을 명시적으로 닫습니다.
6. 라우터의 스트림을 HTTP chunked 형식으로 끝내고 연결을 정리합니다.
   작업 스케줄러의 상태 변경과 실제 TCP 리스너 종료를 모두 확인한 뒤 재시작합니다.
   포트 충돌 검사와 라우터 토큰 지문/새 인스턴스 건강 확인을 추가했습니다.
7. Windows 서비스 갱신, 설치 실패 복원, 제거 및 공유 런타임 정리를 지원합니다.

현재 사용자 설치
- 기본 Codex 앱/CLI 설정: mindlogic_menu_router, gpt-6-sol, high.
  선택된 gpt-6-sol의 실제 목적지는 OpenAI입니다. 앱 재시작 후 설정을 읽습니다.
- 사용자 승인 전 기본 OpenAI 설정은 config.toml.backup-*에 보존됩니다.
- 앱 모델 메뉴: Mindlogic · GPT-6.1 Sol, GPT-6 Astra / Sol / Luna,
  GPT-5.6 Sol / Terra / Luna, GPT-5.5를 표시하도록 구성했습니다.
- 별도 프로필: ~/.codex/mindlogic-menu.config.toml
- 라우터: 127.0.0.1:18762, 사용자 로그온 작업.
- 실행: PowerShell에서 & "$env:USERPROFILE\.codex\bin\mindlogic-menu.cmd"
